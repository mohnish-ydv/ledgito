# M3 reference interpretation

The supplied 17-page screenshot pack was used for product patterns, not visual copying.

## Pages 1-4

Observed patterns:

- transaction detail prioritises amount, account, notes, split, attachments and tags
- dark command-centre dashboard with recent activity and a strong add action
- branded onboarding with a clear financial-growth promise

Ledgerly response:

- a structured transaction editor with a financial hero, grouped route/details/files sections
- a new balance command centre with quick moves, monthly pulse, budget pulse and recent activity
- an original violet/mint onboarding system that keeps Ledgerly's offline-first identity

## Pages 5-10

Observed patterns:

- profile/settings hub
- analytics and monthly budget summary
- expense/income charts
- chronological records
- category-first add flow

Ledgerly response:

- Settings becomes a designed privacy and appearance space
- Insights gains cash-flow hero, custom ring, sparkline, category structure and account movement
- Activity keeps powerful search and filters without exposing a huge category wall by default

## Pages 11-17

Observed patterns:

- a very broad tool drawer: planned payments, budgets, debts, goals, shopping lists, warranties, loyalty cards, currency rates and group sharing
- investments, records, balance trend, upcoming payments and account overview

Ledgerly response:

- a searchable, grouped Money Command Centre prevents those tools from overwhelming primary navigation
- working tools are separated from roadmap previews
- every unfinished feature is explicit and non-destructive
- investments, assets, net worth, planning and connected features are represented as frontend previews only

## Original direction

Ledgerly does not copy Axio, Money Manager or Wallet colours, layouts, logos or navigation. M3 uses the original **Obsidian Aurora** system and preserves Ledgerly's offline-first product position.
