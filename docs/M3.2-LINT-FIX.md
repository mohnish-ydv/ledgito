# Ledgerly M3.2 Lint Fix

M3.2 is a narrow stability patch built from the uploaded M3.1 source. It preserves the Obsidian Aurora UI and the complete Room v2 finance engine.

## GitHub Actions failure addressed

The M3.1 workflow compiled Kotlin successfully, then `lintDebug` reported three API-level errors. The three source-level causes were corrected without lowering lint severity:

1. Light navigation-bar icons require API 27, while the day theme was annotated as API 26.
2. The night theme used the same API 27 attribute without an API target annotation.
3. `android:dataExtractionRules` is an API 31 manifest attribute and now carries an explicit Android 12 target annotation.

## Safety and compatibility

- `lint.abortOnError` remains enabled.
- No lint task is skipped and no issue category is globally disabled.
- Package ID remains `com.mohnishraj.goldmineledger`.
- Room database version remains 2.
- No destructive migration is enabled.
- No INTERNET permission is requested.
- Existing M1/M2/M3 user data remains upgrade-compatible.
