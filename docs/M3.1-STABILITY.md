# Ledgerly M3.1 Stability

## Fixed blocker

GitHub Actions reached `compileDebugKotlin` and failed at `LedgerViewModel.kt` because the injected `SettingsRepository` constructor argument was not retained as a property. The M3 privacy action later referenced `settings`, which was therefore outside scope.

The constructor now declares:

```kotlin
private val settings: SettingsRepository
```

This keeps `setHideAmounts()` connected to the same DataStore-backed repository used by `settingsState`.

## Preserved

- Obsidian Aurora UI and information architecture
- complete M2 finance engine
- package `com.mohnishraj.goldmineledger`
- Room database version 2 and M1/M2 upgrade compatibility
- zero INTERNET permission

GitHub Actions validates source/schema, runs JVM unit tests and Android lint, then assembles the release APK.
