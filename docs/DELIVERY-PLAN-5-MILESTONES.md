# Ledgerly - five milestone delivery plan

## M1 - Foundation
Room database, onboarding, profiles, accounts, categories and core CRUD.

## M2 - Finance engine
Income, expenses, transfers, splits, tags, attachments, recurring rules, budgets, reports and calendar.

## M3 - Visual Intelligence
Original design system, information architecture, privacy masking, redesigned core flows, custom lightweight charts and a safe frontend roadmap for reference features.

## M4 - Reliability and ownership
Backup/restore, CSV import/export, reminders, optional app lock, accessibility, migration tests, performance and full device QA. Roadmap previews are promoted only after their data contracts pass review.

## M5 - Commercial release
Release signing, store assets, privacy policy, monetisation decisions, production QA, staged rollout and support documentation.
