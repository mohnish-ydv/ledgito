# Ledgito 1.2 Professional Experience — Android Lint Fix

## GitHub failure addressed

The supplied GitHub Actions run passed source validation, schema checks, unit tests, and Kotlin compilation. It then stopped at `:app:lintDebug` with two `RestrictedApi` errors in `UiPolish.kt`.

Both errors came from direct use of Material Components' internal `AnimationUtils.FAST_OUT_SLOW_IN_INTERPOLATOR` constant, which application code is not allowed to access.

## Source correction

- Removed the restricted Material `AnimationUtils` import.
- Replaced both internal API references with Android's public `PathInterpolator(0.4, 0, 0.2, 1)` implementation of the same standard Material easing curve.
- Added a deterministic validator guard so the restricted API cannot be reintroduced unnoticed.
