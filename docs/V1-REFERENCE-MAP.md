# Ledgerly 1.0 — Reference-to-Product Map

The supplied 17-page visual reference was treated as feature research, not as a screen template.

| Reference pages | Broad idea observed | Original Ledgerly implementation |
|---|---|---|
| 1 | Detailed transaction, note, split, receipt and tags | Existing Ledgerly transaction editor/history, local attachments, splits and tags |
| 2, 8 | Compact dashboard and recent records | Obsidian Aurora Home and Activity with focused bottom navigation |
| 3–4 | Onboarding | Original three-step local onboarding; no phone login or account requirement |
| 5 | Profile/settings hub | Privacy, theme, currency, app lock, reminders and Data Vault |
| 6–7, 16–17 | Budgets, analytics and trends | Budget Studio, Insights, custom ring/sparkline views, net worth and cash-flow outlook |
| 9–10 | Type/category-first adding | Ledgerly quick add with account/category validation and editable category hierarchy |
| 11–12 | Planned payments, debt, goals, shopping, warranties, loyalty, rates, sharing, assets and cash flow | Searchable grouped live tools behind More, rather than a crowded drawer |
| 13–14 | Investments | Manual holdings with cost basis, current value and update history; no fake brokerage sync |
| 15 | Time-filtered records | Activity filters, saved views, sort options, calendar and report presets |

Ledgerly intentionally does not reproduce branding, colours, screen composition, premium prompts, bank-sync claims or drawer structure from the references.
