# Ledgerly M3.3 Lint Final

M3.3 is a narrow build-stability patch based directly on the uploaded M3.2 source and the complete GitHub Actions log.

## GitHub failure analysed

The run completed Kotlin compilation and `testDebugUnitTest`, then failed `lintDebug` with one unique error:

```text
fragment_dashboard.xml:528: No orientation specified [Orientation]
```

GitHub repeated this same issue in the job summary and annotations; it was not four independent source errors.

## Fix

- `legacyStats` now declares `android:orientation="vertical"`.
- `auditContainer` now declares `android:orientation="vertical"`.
- The project validator scans every layout variant and fails if any `LinearLayout` lacks an explicit orientation.

No lint baseline, suppression, or `abortOnError` bypass was added. Package ID and Room database version remain unchanged.
