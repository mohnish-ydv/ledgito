# Release Scope and Non-Goals

## v1 release scope

Everything marked P0 in the feature catalogue is mandatory. In particular, every directly requested review feature is included:

- Receipts and attachments
- Reliable CSV export
- Complete backup and restore
- Six-month, yearly and custom-range reports
- Custom-period budgets
- Advanced filters
- Transfers
- Recovery after uninstall through user-owned external backup
- Recurring payments
- Calendar date navigation
- Guided setup
- Correct budgeting after month one

## Explicit non-goals for v1

- Connecting to bank credentials
- Scraping SMS, email or notifications
- Financial advice or credit scoring
- Automatic cloud account
- Social feed
- Cashback or affiliate products
- Ads between transaction entries
- AI features requiring an API
- Requiring internet for ordinary use

## Scope-control rule

A new feature may enter v1 only if it is required for correctness, data safety, accessibility or one of the review-mapped workflows. Everything else must wait for P1/P2.
