# Definition of Done

A feature is done only when:

- UI and empty/loading/error states exist
- Domain rules are outside UI code
- Persistence survives process death
- Accessibility labels and large text are tested
- Unit tests cover normal and edge cases
- Relevant integration tests pass
- Backup/export impact is handled
- Migration impact is documented
- Review traceability acceptance is satisfied
- No known critical/high-severity defect remains

Phase 0 is done because every required decision above is documented and machine-readable. Implementation is the next phase.
