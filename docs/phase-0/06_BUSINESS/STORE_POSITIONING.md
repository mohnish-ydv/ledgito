# Store Positioning

## Short description

Offline expense, budget, transfer and receipt tracking with backups you control.

## Core listing messages

1. Works without internet
2. No account required
3. Transfers and recurring payments included
4. Attach receipts
5. View any date range
6. Back up and restore your complete data

## Trust claims allowed only after testing

- “Complete backup includes attachments” only after attachment round-trip tests pass.
- “No data sent to our servers” only while no component transmits financial data.
- “Works offline” only if every core screen and report works in airplane mode.
