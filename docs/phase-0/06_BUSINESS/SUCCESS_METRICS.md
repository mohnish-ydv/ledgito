# Success Metrics

Because v1 has no analytics SDK, early metrics come from opt-in feedback and local diagnostics shared by testers.

## Product metrics

- First account created
- First transaction created
- First budget created
- Backup configured
- Verified restore completed in testing
- Seven-day continued use
- Export success rate
- Crash-free sessions from GitHub/pre-release testing where logs are voluntarily provided

## Quality targets

- 100% pass for backup/restore golden tests
- 0 known data-loss defects at release
- 0 known duplicate recurring-entry defects
- 0 known transfer-reporting defects
- 100% review-mapped P0 feature acceptance
- Cold start target under 2.5 seconds on a representative mid-range device
- Smooth ledger browsing with 20,000 transactions
