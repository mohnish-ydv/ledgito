# Critical UX Flows

## First successful session

Welcome → choose currency → create Cash account → optionally add opening balance → add first expense → see Home update → create first monthly budget → choose backup folder → completion summary.

## Quick expense

Tap Add → Expense → enter amount → choose recent category → Save.  
Target: repeat users complete in three meaningful interactions after opening the editor.

## Transfer

Tap Add → Transfer → choose source/destination → amount → Save → both account balances update atomically → income/expense reports unchanged.

## Receipt capture

Open transaction editor → Attach → Camera/File → preview → Save → attachment copied to private vault → backup-needed state becomes true.

## Recurring bill

Recurring → Add → choose expense template → monthly schedule → reminder-first or automatic → save → next occurrence preview shown.

## Review any date range

Insights → period selector → Custom → choose dates → Apply → chart and table update → drill into matching transactions → Export current view.

## Backup and recovery

Settings → Backup → choose destination → Back up now → verify success. After reinstall: Welcome → Restore backup → select file → integrity check → preview → restore → compare count/totals → continue.

## Failed restore

Select damaged package → integrity failure shown → current data remains untouched → user can open error details or select another package.

## Budget month transition

Current budget reaches period end → next period generated once → carry-over applied according to setting → old period remains unchanged → user navigates previous/next without loss.
