# Information Architecture

## Primary navigation

Bottom navigation contains four destinations:

1. **Home** — balances, quick summary, budget status and recent entries
2. **Transactions** — searchable chronological ledger
3. **Budgets** — active periods and budget history
4. **Insights** — reports and comparisons

A persistent centred or trailing **Add** action opens expense, income or transfer creation.

## Secondary navigation

Accessible from the top app bar/profile menu:

- Accounts
- Recurring
- Categories and tags
- Attachments
- Backup and restore
- Settings
- Help and diagnostics

## Navigation rules

- Back never silently discards edits.
- A dirty form asks Save draft, Discard or Continue editing.
- Date-range state is preserved when moving between report screens.
- Filters survive temporary navigation but can be cleared in one action.
- Transfer creation is never hidden inside expense creation.
- Backup and restore are reachable within two taps from Settings.
